## 地图预览的依据

`metadata/layouts/`保存项目V11已有的三个seed=91026布局快照。它们包括真实cells、route、zones、structures、tasks。本批仅读取快照生成审片图，没有修改关卡生成器。

预览按世界格坐标对512px地面做4×4切片，保留分区覆盖顺序，并使用结构真实position与width。边界装饰按现有摆放策略结合新素材完整画布重新推导；换图后数量可能与灰盒不同。

预览为离线拼装，**不是Unity截图**：外围8格着色瓷砖没有复现，使用奶油色审片底；没有复现动态人流、可推物、全部任务实体、红绿灯与任务进度。列车固定展示开门图。总览的路线和任务文字是审片覆盖层，不在素材内；人物只放在独立比例参照栏。

## 规格与追溯

- `source/generated/{common,street,metro,office}/`：选定及保留首稿，均为单层栅格PNG，不等同分层PSD/KRA源稿。
- `metadata/*-prompts.json`：完整生成提示词、参考图、生成源路径与修订说明。
- `metadata/*-export-config.json`：各组原始画布、人工估定锚点及导出比例；`export-config.json`是合并配置。
- `metadata/manifest.json`：全部输出、尺寸、锚点、世界宽度、源图和导出SHA256。
- `metadata/validation.json`：34项尺寸、透明角、外边缘、包围盒和地面边缘统计；技术检查0告警。统计不能替代视觉或玩法验收。
- `metadata/layout-provenance.json`及`preview-render-report.json`：布局来源和预览范围。

重做导出：`pwsh -File Tools/Export-MapArtV002.ps1`。重做预览：`pwsh -File Tools/Preview-MapArtV002.ps1`。从项目根执行，工具只写美术包，不改游戏资源和逻辑。
