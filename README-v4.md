# 早八冲刺 v4：双向冲撞

三段大地图连续通勤：骑车赶地铁、挤早高峰、抢最后打卡。橙色背包角色是你，青色区域是目的地。

v4 保留 v3 的主动冲刺撞飞、短暂停顿、果冻压缩回弹和有限连锁；部分急躁通勤者也会沿自己的赶路方向蓄力冲撞。地面先显示锁定方向和范围，玩家可以躲开，或在命中前按住 Shift 稳住重心，避免被击飞。普通身体接触仍是轻推。

- WASD / 方向键：移动。
- Space：冲刺撞飞。冲刺不提供受击免疫。
- Shift：稳住重心，移动较慢，地面稳住时抵御预警冲撞的击飞。
- Esc：暂停；暂停或结算时 R：重开；M：声音开关。
- 菜单/暂停页可关闭轻微震屏。三关共享 110 秒，超时仍可完成并获得迟到结算。

源码位于 `EarlyRushUnityV4`，使用 Unity 6000.0.26f1、Windows x64、D3D11。批处理构建入口为 `BuildEarlyRush.Build`，独立输出目录为 `artifacts/EarlyRush-V4-Windows`。v3 工程、分支和成品包保留。

实际验收、失败历史和性能采样范围见 `docs/v4-validation.md` 与 `docs/v4-prototype-log.md`。交付大小及 SHA 清单以最终生成的 v4 发行清单为准。

验收边界：最终四条自然路线中，玩家被 NPC 击飞均为 0 次。未稳住时腾空与 Shift 防击飞的对照来自受控专项；这些结果不能证明自然流程中的威胁频率已经合适，也不是真人难度或手感验收。当前仍记录到约 402ms 的偶发长帧。本轮补充说明不改玩法数值、游戏二进制或已交付压缩包。
