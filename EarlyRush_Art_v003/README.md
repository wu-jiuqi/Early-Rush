## 地图范围与策划依据

原策划为《Early Rush 三阶段关卡设计方案 v3》，本包保存原DOCX附录图片及来源哈希，见 `reference/original-design/`。画风依据原街道附录：固定北向、高俯视、圆润青绿建筑、奶油铺地、黄色路缘。没有沿用上一批独立素材作为风格母版。

地图范围以现有seed91026首关量级校对：可走格包围157×326世界单位、九段主路线565单位、八次转折；16:9运行镜头约26.667×15单位，整关约5.89屏宽、21.73屏高。完整量级不能用几间店围成的一两个路口代替，更不能靠插值放大图片代替扩大街区。

当前艺术总图保留九段骨架、前段早餐、中段修车、后段翻板及远端地铁入口，**是这一量级的整体美术参考，不是灰盒坐标的精确投影**。生成过程仍改变了局部段长、庭院和背景通路形状。真实cells、碰撞与路线长度没有因这批图而被修改。依据及实际尺度证据见 `reference/design-requirements.md` 和 `reference/layout-guide/`。

## 回拼方法与质量边界

每块先以原总图裁片为直接参考分别生成，禁止重新设计整个小场景。初次使用原图边缘保留的方案产生低清带与重影，已弃用。最终不再回贴低清总图边缘，而用10张跨边界修复图及3张白线定点图修复路缘、白线、建筑和铺地；技术合成只负责坐标、缩放与60px边缘羽化。修复后再切回8块，因此最终地块彼此按同一连续成图衔接。

外部工具不能保证生成图每一像素都不变。修复和组装检查也不等于用户美术验收或玩法验收。完整画面仍需在实际游戏镜头下复核：精确净宽、任务回推空间、行走边界、碰撞对齐、物体尺寸、遮挡与镜头裁切。部分背景小路可能暗示灰盒中不存在的捷径，接入前必须明确视觉边界，不得靠隐形墙掩盖。地图地块不是可任意轮换拼接的通用Wang/自动铺砖集合。

当前都是单层PNG及独立图层配置，并非PSD/KRA分层母版；原始生成尺寸与最终拼图尺寸明确分开。导出PNG尚无正式运行时pivot映射，不可直接批量覆盖V8Art资源键。

## 重现技术步骤

从项目根执行：

```powershell
pwsh -File Tools/Build-StreetLayoutGuideV003.ps1
pwsh -File Tools/Split-Assemble-StreetArtV003.ps1 -SkipSlices -AssemblyConfig EarlyRush_Art_v003/metadata/assembly-config.json
```

脚本负责技术图、裁切和现有PNG定位合成，不替代图像生成。未修缝整图和旧临时诊断导出可由脚本重建，保留在本机并从Git排除，避免与最终地块重复存储；选用艺术原图、修复图、最终地块和两张完整成图均纳入版本记录。修复输入来自未修缝回拼图，`-PrepareSeamInputs` 可重新裁出上下文；重新生成仍须使用已保存的图像提示词和参考图片。
