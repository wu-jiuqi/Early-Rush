## 场景与拓扑

三阶段独立运行与计时：马路通勤 → 地铁通勤 → 办公室早会。各阶段各三项可选任务；完成任务不是继续通勤或通关的前提。完整参考板可同时展示三阶段，但不能误画成一条可直接步行贯穿的物理大地图。[正文5、22、26行]

| 阶段 | 建议路线骨架 | 必须在完整图中表达的空间 |
| --- | --- | --- |
| 马路 | 出生人行道 → 早餐支路 → 受控过街口 → 修车店 → 翻面支路 → 地铁入口 | 早餐摊前中段；修车店两个独立轮子及可容纳两轮的检查区；修车后仍有有效骑行路程；翻板固定底座与退步空间；信号灯、停止线、人行横道和等待区。[108–123行] |
| 地铁 | 站厅 → 闸机 → 候车区 → 车厢 → 到站站厅 → 出口 | 车门中央下客通道与两侧安全候车位；站厅侧边纪念扭蛋机，能后退再碰；到站厅侧边水渍与厚折叠抹布，可绕行和回推，避开出站结算区。[125–139行] |
| 办公室 | 前台 → 开放办公区 → 文件领取点及领导工位 → 散落办公椅区 → 会议室内参会区 | 多条可绕行咖啡同事走廊；文件与领导工位匹配头像；任务椅与空检查点数量相同，每点一椅，桌边两侧可接近；会议室门口不等同终点。[141–154行] |

地图采用固定通勤骨架、可替换模块、受约束任务支路。建议每阶段8–10个主线模块，至少3次明确左右转折；任务分布前中后段并回接主线。直道、缓冲、左右转角、过街口、任务房间、连接/出口需共同构成完整环境，不是沿空白背景摆放单独物件。[186–217行]

尺度是试玩起点而非定稿：主线净宽4–6倍玩家体宽，任务通道3–4倍；推物目标区另留回推空间。原稿建议主线约5–6分钟、全任务约6–7分钟、阶段上限7分钟，尚需调参，不能从示意图虚构固定世界长度。[87、208–212行]

## 不得擅改的约束

- 九任务均可绕行；翻板不控制店铺或道路开放，扭蛋不是售票机，清洁任务不封锁出口，任务失败不堵主线。[22、123、133、137、142行]
- M1先下后上不加专属箭头、气泡、预警或成功提示；正常候车线、车门灯、开门动作保留。不能把审片任务标号烘焙进运行地块。[129行]
- 办公室终点是会议室内参会区，不能恢复打卡机；椅子检查点不得与文件交付区/参会区重叠。[141、154行]
- 车轮、椅子、抹布、杯子、文件、翻板面、门叶、人物等互动或可变对象在拆分时必须独立；可选任务区留回推、安全站位和通行侧，装饰不能占这些空间。[105–106、118、135、139、154、215行]
- 背景完整参考图用于统一空间与美术基准，不代表通过碰撞、可达性、时间预算或实机验收。后续切分须记录每个地块的连接口、地面/前后遮挡层与独立资源，重新组装后再验证。[214–215、257行]
