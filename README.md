# Early Rush · 三阶段通勤

当前分支基于提交 `847668c` 接入 V15 图标 UI。Unity **6000.0.26f1**，Unity UI **2.0.0**；最新入口是 `Assets/Scenes/EarlyRushV15.unity`。实现、动画参数和验证范围见 [V15 UI接入说明](Docs/V15-UI接入说明.md)。

## 运行

用 Unity Hub 打开仓库，打开 V15 场景并按 Play。准备页点击播放图标后开始计时。当前默认 V4 三章布局每章使用600秒预算，界面从实际配置读取时限；任务可选，按时抵达即可推进。

WASD／方向键移动，Space 点按冲刺，按住 Shift 稳步抗撞／骑行稳车，Esc 暂停或关闭当前说明，R 救回附近未完成物体，Tab 展开地图，F1 帮助。点击任务图标可看说明或图解；设置中可调音量、静音和减弱动态效果。

新界面已接入110张素材，覆盖选关、暂停、三章任务 HUD、小地图、世界提示、教学和结算。地图、角色与九任务模拟继续使用现有系统。地铁 M1 保持隐藏；失败任务星不会解锁下一章。

## V15 构建与检查

Unity 菜单 `Early Rush > V15 > Prepare Validate and Build Windows` 准备新场景、检查 UI 与专项机制，再构建至 `Builds/EarlyRush-V15/EarlyRush.exe`。命令行对应方法为 `BuildEarlyRushV15.Build`。该入口会重建 V15 场景，不覆盖 V13／V14 场景。

运行成品附加 `--v15-ui-qa`，生成新界面的按钮射线命中、listener、状态夹具、三种分辨率地图投影、序列帧及截图记录到 EXE 同级 `QA/ui-v15/`。附加 `--legacy-ui` 可对照旧 OnGUI。

已完成 Unity 编译与 Windows 构建，110张资源校验、756项机制断言和252项运行界面检查通过，21张实际截图有效。详见 [V15验收记录](Docs/V15-验收/README.md)。本轮 UI 检查含显式状态夹具，不等于完整三章通关或真人试玩验收。

## 历史 V13 记录

以下资料保留 V13 当时的运行、人口和验收信息；其中入口、预算和美术状态不是当前 V15 的交付说明。

### 历史运行方式

用 Unity Hub 打开仓库根目录，打开 V13 场景，按 Play。每阶段独立 7 分钟，准备页按“出发”才计时。WASD / 方向键移动，Space 冲刺并撞开普通行人，按住任一 Shift 稳步抗撞（骑车时稳车减速），Esc 暂停，R 回位附近未完成物件，Tab 展开地图，F1 操作提示。任务可选，按时抵达即可推进。

冲刺冷却缩短到 0.65 秒，冷却末尾 0.14 秒可缓存一次按下，尾段平滑收速；按住 Space 不会自动连发。小地图和全图统一底图与标记投影，窗口缩放和转向时玩家箭头保持在对应地面位置。

三个阶段分别有早餐/修车/翻板、候车/扭蛋/清洁、咖啡/文件/椅子任务。完成一项与完成三项各加一星；超时的任务星只记挑战结果，不解锁下一阶段。

当前街道、地铁、办公室分别生成 760、900、700 名独立行人，沿整条道路分布，主要进行双向跨路段通勤，交汇处更密集；任务工作区与平行旁路留出空间。贯穿通勤者经过主路转角，部分访问者使用公共侧路，每人保留自己的目标、路径、让行和短停。办公室保留最多 40 名端杯同事，具有护杯、洒杯反应和空杯返位行为。

### 历史构建与验收

Unity 菜单 `Early Rush > V13 > Validate and Build Windows` 会先验证规则、冲刺缓冲、独立行人 AI、沿路覆盖、咖啡行为、双向撞飞、小地图、镜头、100 个种子的三阶段地图、主线与默认 420 秒下的完整任务输入回放，再构建到 `Builds/EarlyRush-V13/EarlyRush.exe`。

也可运行 `Tools/Build-V13.ps1 -UnityPath <Unity.exe路径>`，加 `-ValidateOnly` 仅验证，加 `-Quick` 只做专项、不证明路线完成。运行成品附加 `--v13-runtime-qa` 会自动生成三阶段人流的前后样本及沿路对比、双向撞飞、冲刺缓冲、咖啡行为和三种分辨率的小地图像素检查到成品目录的 `QA/runtime-v13`，随后退出。

仓库缺少的 V8 美术以确定性占位图显示，可直接构建。将正式 PNG 放入 `Assets/Resources/V8Art/<资源键>.png` 后会优先使用原图。占位美术不代表最终视觉品质。

V13 实现和验收见 [V13 冲刺、小地图与沿路人流](Docs/V13-冲刺小地图与沿路人流.md)，独立 AI 和双向撞飞基础见 [V12 制作记录](Docs/V12-独立行人AI与双向撞飞.md)，原九任务实现见 [V10 制作记录](Docs/V10-设计v3优化.md)。这些构建入口保留用于追溯，最新 UI 应使用上文 V15 入口。

美术制作见 [素材清单与接入规范](Docs/美术交付/EarlyRush-美术素材清单与接入规范-v1.md) 和 [63项生产清单](Docs/美术交付/EarlyRush-美术生产清单-v1.csv)。新增动作已有状态驱动的占位姿态和地面阴影，正式序列帧播放器与美术仍待接入。
