# Early Rush · 三阶段通勤

本分支基于 `dev/v9-review`，按《Early Rush 三阶段关卡设计方案 v3》继续开发。Unity **6000.0.26f1**；当前入口是 `Assets/Scenes/EarlyRushV12.unity`。

## 运行

用 Unity Hub 打开仓库根目录，打开 V12 场景，按 Play。每阶段独立 7 分钟，准备页按“出发”才计时。WASD / 方向键移动，Space 冲刺并撞开普通行人，按住任一 Shift 稳步抗撞（骑车时稳车减速），Esc 暂停，R 回位附近未完成物件，Tab 展开地图，F1 操作提示。任务可选，按时抵达即可推进。

三个阶段分别有早餐/修车/翻板、候车/扭蛋/清洁、咖啡/文件/椅子任务。完成一项与完成三项各加一星；超时的任务星只记挑战结果，不解锁下一阶段。

当前街道、地铁、办公室分别生成 760、900、700 名独立行人，主要汇集在四个高峰节点，持续穿行、让路和缓慢跟进；任务工作区与平行旁路留出空间。办公室保留最多 40 名端杯同事，具有护杯、洒杯反应和空杯返位行为。

## 构建与验收

Unity 菜单 `Early Rush > V12 > Validate and Build Windows` 会先验证规则、独立行人 AI、咖啡行为、双向撞飞、镜头、100 个种子的三阶段地图、主线与默认 420 秒下的完整任务输入回放，再构建到 `Builds/EarlyRush-V12/EarlyRush.exe`。

也可运行 `Tools/Build-V12.ps1 -UnityPath <Unity.exe路径>`，加 `-ValidateOnly` 仅验证，加 `-Quick` 只做专项、不证明路线完成。运行成品附加 `--v12-runtime-qa` 会自动生成三阶段独立人流的前后样本、双向撞飞与咖啡行为检查到成品目录的 `QA/runtime-v12`，随后退出。

仓库缺少的 V8 美术以确定性占位图显示，可直接构建。将正式 PNG 放入 `Assets/Resources/V8Art/<资源键>.png` 后会优先使用原图。占位美术不代表最终视觉品质。

实现范围与后续工作见 [V12 独立行人 AI 与双向撞飞](Docs/V12-独立行人AI与双向撞飞.md)，原九任务实现见 [V10 制作记录](Docs/V10-设计v3优化.md)。历史构建入口保留用于追溯，当前共享规则已更新，构建应使用 V12。
