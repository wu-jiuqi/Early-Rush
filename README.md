# Early Rush · 三阶段通勤

本分支基于 `dev/v9-review`，按《Early Rush 三阶段关卡设计方案 v3》继续开发。Unity **6000.0.26f1**；当前入口是 `Assets/Scenes/EarlyRushV13.unity`。

## 运行

用 Unity Hub 打开仓库根目录，打开 V13 场景，按 Play。每阶段独立 7 分钟，准备页按“出发”才计时。WASD / 方向键移动，Space 冲刺并撞开普通行人，按住任一 Shift 稳步抗撞（骑车时稳车减速），Esc 暂停，R 回位附近未完成物件，Tab 展开地图，F1 操作提示。任务可选，按时抵达即可推进。

冲刺冷却缩短到 0.65 秒，冷却末尾 0.14 秒可缓存一次按下，尾段平滑收速；按住 Space 不会自动连发。小地图和全图统一底图与标记投影，窗口缩放和转向时玩家箭头保持在对应地面位置。

三个阶段分别有早餐/修车/翻板、候车/扭蛋/清洁、咖啡/文件/椅子任务。完成一项与完成三项各加一星；超时的任务星只记挑战结果，不解锁下一阶段。

当前街道、地铁、办公室分别生成 760、900、700 名独立行人，沿整条道路分布，主要进行双向跨路段通勤，交汇处更密集；任务工作区与平行旁路留出空间。贯穿通勤者经过主路转角，部分访问者使用公共侧路，每人保留自己的目标、路径、让行和短停。办公室保留最多 40 名端杯同事，具有护杯、洒杯反应和空杯返位行为。

## 构建与验收

Unity 菜单 `Early Rush > V13 > Validate and Build Windows` 会先验证规则、冲刺缓冲、独立行人 AI、沿路覆盖、咖啡行为、双向撞飞、小地图、镜头、100 个种子的三阶段地图、主线与默认 420 秒下的完整任务输入回放，再构建到 `Builds/EarlyRush-V13/EarlyRush.exe`。

也可运行 `Tools/Build-V13.ps1 -UnityPath <Unity.exe路径>`，加 `-ValidateOnly` 仅验证，加 `-Quick` 只做专项、不证明路线完成。运行成品附加 `--v13-runtime-qa` 会自动生成三阶段人流的前后样本及沿路对比、双向撞飞、冲刺缓冲、咖啡行为和三种分辨率的小地图像素检查到成品目录的 `QA/runtime-v13`，随后退出。

仓库缺少的 V8 美术以确定性占位图显示，可直接构建。将正式 PNG 放入 `Assets/Resources/V8Art/<资源键>.png` 后会优先使用原图。占位美术不代表最终视觉品质。
