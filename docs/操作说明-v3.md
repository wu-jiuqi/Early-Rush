# 早八冲刺 v3：操作说明

本文对应独立工程 `EarlyRushUnityV3/` 的 v3 成品构建。该构建的实际 Windows Player 撞击专项 189 项、四路线验收 260 项均通过；详细数据与限制见 `v3-validation.md`，发行文件和校验见配套清单。

## 目标与流程

骑车赶往地铁站 → 穿过站台进入车厢 → 穿过公司大厅与走廊打卡。三段大地图、平滑跟随镜头、青色目标和玩家头顶的“你”标识保留。

三段共享 **110 秒**通勤时限。暂停和阶段转换不消耗通勤计时；撞击产生的短暂停顿仍计入通勤时间。超时后可继续完成三段，最后得到迟到结算，不会直接结束游戏。

## 操作

| 操作 | 按键或入口 |
|---|---|
| 移动、转向 | WASD / 方向键 |
| 短冲刺并撞飞通勤者 | Space；松开后再按，观察冷却条 |
| 稳住、抗侧向推挤 | 按住 Shift；移动变慢，同时取消冲刺 |
| 暂停 / 继续 | Esc，或暂停菜单按钮 |
| 开始 / 确认教学 / 结算后再次出发 | Enter |
| 从第一段重新开始 | 暂停或结算时按 R |
| 开关声音 | M，或菜单声音按钮 |
| 开关轻微震屏 | 主菜单或暂停菜单中的“震屏”按钮；没有单独快捷键 |

换关、重开或恢复后，先松开 Space / Shift 再重新按下，避免上一状态的长按自动触发新动作。

## 轻推与冲刺撞飞

普通移动碰到通勤者时，以轻推和小幅回弹为主，不需要一直按住 Shift 才能正常赶路。拥挤处仍需看清墙角、门口与人流方向。

按 Space 冲刺命中通勤者，会出现更强的卡通反馈：角色挤压后拉伸、对方被撞飞并翻滚、落地回弹，再恢复赶路。附近通勤者可能被连带撞开，但连锁人数与传播层数有限，不会无止境扩散。

冲刺可以帮助打开局部空隙，也可能把人群推到下一个瓶颈。墙和地图边界始终阻挡移动；撞飞不代表穿墙。提前转向、在合适时机冲刺，比持续顶着墙角更有效。

## Shift 与震屏开关

Shift 适合在窄处调整方向或抵抗侧向推挤；代价是移动变慢。**Shift 优先于 Space，会取消当前冲刺，因此不能边稳住边撞飞。** 想重新冲刺时先松开 Shift，等待冷却结束再按 Space。

偏好更平稳画面时，可在主菜单或暂停菜单关闭震屏。关闭的是撞击带来的镜头晃动；跟随镜头、果冻形变、短暂停顿与音效仍按各自规则工作。声音可单独通过 M 开关。

## 暂停、重开与结算

暂停时通勤计时和场景运动停止；短暂撞击闪光、震动与停顿会清理，避免恢复后补播旧效果。重开从骑车段重新开始，清空本轮计时、碰撞、冲撞和分段记录。返回主菜单或换关也会处理当前冲撞状态。

结算仍显示通勤时间、碰撞和各段成绩。v3 的冲撞反馈并不表示“碰撞次数越多成绩越好”；是否准时仍由共享时间决定。

## 运行与范围

Windows Player 构建目标是 Windows x64 / Direct3D 11；收到 v3 ZIP 后需完整解压，保留 EXE、Data、UnityPlayer.dll 和其他依赖一起运行。源码工程使用 Unity 6000.0.26f1，v3 构建输出目录为 `artifacts/EarlyRush-V3-Windows/`，与 v2 分开。

程序化圆润卡通模型、果冻形变、冲撞闪光和短音效由项目代码生成，没有新增购买付费资产。画面属于可继续打磨的玩法原型。

## 验收状态与限制

同一 build6 已完成实际 Windows Player 验收：碰撞专项 189 项通过、0 失败，四路线 260 项通过、0 失败。分包合并后已核验全部 142 个原包文件，解压启动另通过 24 项基础检查、0 失败并正常退出。性能、通关时间和限制见 `v3-validation.md`；发行校验见 `v3-release-manifest.md`。

自动化测试区分两类：普通三段路线的连续输入通关，以及专门初始化的冲撞测试场景。后者只能说明局部机制，不可替代三关通勤验收。两类均不等于操作系统键盘自动化或真人试玩；没有据此声称手感已被真人完整验证。
