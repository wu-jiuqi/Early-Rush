## 启动游戏

1. 当前先使用完整本地目录 `D:\CodexWorkspace\2026-10-31\task-4\artifacts\EarlyRush-V2-Windows\`。后续若获得 Windows x64 ZIP，应**完整解压**到普通文件夹，不要直接在压缩包中运行。
2. 双击 `EarlyRush.exe`。请保留同目录的 `EarlyRush_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 及压缩包内其余依赖文件；只复制 EXE 无法构成完整游戏。
3. 点击游戏窗口获得输入焦点。开始菜单会显示教学，可用鼠标或 Enter 确认。

玩家运行游戏不需要安装 Unity，不需要登录账号或联网。当前工程使用 Unity 6000.0.26f1，输出为 Windows 64 位、Direct3D 11。该构建已在当前 Windows 测试机上通过实际 Player 输入驱动验收；完整记录见仓库中的验收报告，尚未覆盖其他显卡、系统或机器。

默认窗口为 1280 × 720，可调整窗口大小。窗口失去焦点时普通游戏会自动暂停，回到窗口后继续。

## 操作

| 按键 | 操作 |
|---|---|
| WASD / 方向键 | 移动；斜向不会获得额外基础移速 |
| Space | 短冲刺；按一次触发，观察右下方冷却条，松开后再按 |
| Shift | 按住稳住，减速并抵抗推挤；优先于冲刺，会取消当前冲刺 |
| Esc | 暂停 / 继续 |
| M | 开关声音 |
| Enter | 开始、确认教学；结算时再次出发 |
| R | 在暂停或结算界面重新开始完整流程 |

暂停菜单也提供继续、重新出发、返回主菜单和声音按钮。重开会从骑车段重新出发，清空本轮计时、碰撞和分段记录。换关、重开或恢复时，如 Space / Shift 没有立即响应，先松开再按，避免把上一状态的长按误当作新动作。

## 三段通勤

从家门口骑车赶往地铁站，穿过站台人流并挤入车厢，最后穿过公司大厅和走廊抵达打卡区。每段都是超过单屏范围的大地图；镜头会随移动平滑推进，并提前朝运动方向预看。青色标记是该段目标，屏幕边缘的目标提示帮助判断方向；玩家头顶的“你”标识辅助在密集人群中找到自己。

所有行人也在赶路，会朝目的地移动并在路口、入口和通道汇聚。先观察人流方向及空隙，再决定冲刺、让行或绕开；离开视野的通勤人流会回收并继续补入路线。

- **骑车段**：沿道路推进，留意交叉人流和施工区域。直通路线更短，侧向绕行增加路程但能避开部分交汇点。
- **地铁段**：经过闸机、站台和拥挤区后抵达车门。提前对齐入口，给侧向来人留下空间；在窄处盲目连续冲刺容易损失控制。
- **公司段**：从入口大厅穿过走廊到打卡区。利用走廊间隙和不同路线，避免与同事同时抢同一处门口。

短路不保证更快，绕路也不保证完全没有碰撞。通勤效率取决于路线、到达时机与稳住/冲刺决策。

## 冲撞、稳住与脱困

冲刺撞进拥挤人流可能失衡。界面会显示失衡或恢复提示，系统提供短暂的恢复保护，避免一次接触无限连续剥夺控制。恢复保护不等于可以穿墙或无视其他行人。

被挤住时，松开冲刺，按住 Shift 稳住，先向空侧或来路退一点，再选择可见空隙通过。Shift 会降低移动速度，所以空旷路段不必一直按住。不要把角色持续顶在墙角或正面迎向整股人流。

## 计时与结算

三段共享 **110 秒**通勤时限。阶段转换与暂停不会消耗通勤计时；下一段会保留本轮累计时间。计时超限后游戏继续，仍可完成三段并得到迟到结算，不会直接判失败或把玩家送回起点。

结果界面显示总通勤时间、碰撞次数、各段耗时和提前或迟到时间。每次重开都会重置本轮状态；目前没有永久进度存档。

## 美术与音效范围

这是程序化搭建的圆润卡通灰盒原型：玩具感俯视场景、橙衣背包玩家、青色目标。角色、场景造型和短音效由项目代码生成，没有购买或使用付费资产。当前重点是地图推进、可观察人流和操作决策，尚不是商业成品美术。

## 测试方式与限制

验收程序运行在实际 Windows Player 中，通过游戏的正常移动、冲刺和稳住输入接口控制角色。测试不会通过传送玩家或直接完成关卡来代替行走，但这种方式属于 **Player 内输入驱动自动化**，不是操作系统键盘自动化，也不是声称真人试玩。

验收报告分别记录了风险、绕行、直冲和超时继续的路线结果，并说明自动策略的主动等待与避让方式。风险/绕行驱动较保守，不是熟练玩家的最优路线成绩。自动化能验证几何、状态、输入、镜头和数值结果，不能证明手感已被真人完整验证。当前尚未进行多设备兼容性、长期稳定性或充分的人群策略采样。
