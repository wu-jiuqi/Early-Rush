# v4 双向冲撞实现

仅在独立 v4 工程内复用 v3 的飞行、回弹、有限连锁及静态障碍扫掠。NPC 沿已有目的地路线抢道，不转为追击玩家的敌人。

- NPC 预警 0.90 秒，创建的渲染帧不扣倒计时。起点、方向和长度锁定；视觉子节点前倾、压低和轻微摇摆，不缩放碰撞根节点。
- 冲撞速度 11.5 米/秒，时长最多 0.32 秒，地面胶囊半径 0.82 米表示玩家中心危险区。路径在第一处静态障碍前截短；撞墙停止，不能滑出原预警区。实际命中采用当次移动的相对扫掠，而非提前伤害整条预警范围。
- 常规全局发起间隔 1.5 秒，最多 2 个预警/冲撞状态；仅视野内的合适通勤者发起。预警期间离开视野则取消。取消、暂停、击飞、回收会清除攻击。
- 玩家在地面按 Shift 稳住时，免于主动冲撞的击飞，允许 0.07 米小推，出现成功反馈。冲刺不提供无敌。
- 玩家飞行初速度水平 9.4、垂直 7.2，重力 19.5；落地恢复 0.40 秒，落地保护 1.2 秒。空中、恢复期及保护期不重复击飞。
- NPC 互撞复用最多 6 人、2 层的连锁。飞行链体不击飞玩家。NPC 攻击记录按实际创建顺序保留最近 8 个，避免取消预警造成编号跳号泄漏。
- 角色和相机不依赖全局 timeScale 暂停。暂停取消警告与冲撞并清除 hit-stop，保留已发生的飞行状态冻结；重开和切关全部重置。

普通步行使用0.60米中心间距的防深入底线，位于原0.78米软分离目标以内，允许侧滑、离开和有限挤压。已经深重叠时由原3米/秒共享分离预算渐进解开；步行不继续钻入邻体。约束包含已落地恢复体和锁定预警体，不约束空中体、主动冲撞或玩家的击飞力量。墙体处理改变移动方向后再核对实际位移；没有安全方向时只等待当前物理步，后续仍能尝试侧移。

普通导航保留原0.35米到点条件；被推过中间点后，如果已越过入段终点平面，且从当前位置到下一点的整个0.40米半径胶囊路径没有静态障碍，则继续下段。角色位置仍通过原步行和碰撞移动，不传送；避免已经越过转折点却回头钻入队列。路径检查保留真实圆角净距，跨墙时不跳过转折点。新增的路点、当前目标、朝向和堵塞时间探针用于核对失败快照。

性能范围仅做小修：重复建场的玩家定位圈/冲刺轨迹材质改为实例复用，在销毁时释放；新增建场耗时标记。旧 v3 的偶发 550ms 长帧不能仅凭这一修改宣称消除，须结合最终 Player 结果说明。
