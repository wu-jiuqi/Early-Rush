# 早八冲刺 v4 操作说明

解压完整包后运行 `EarlyRush.exe`，保留旁边的 `EarlyRush_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 等文件。若下载的是 Engine 和 Game 两份普通 ZIP，请分别“全部提取”，两次明确选择同一个新建文件夹，最后运行其中 `EarlyRush-V4-Windows/EarlyRush.exe`。不要在 ZIP 内直接运行，也不要把两包解压进不同的默认目录。

## 赶路

橙色背包角色是你，青色区域是目标。WASD 或方向键移动，Space 冲刺撞开人群；撞击会产生短暂停顿、果冻挤压和击飞回弹。三段路线共享 110 秒：骑车赶地铁 → 挤早高峰 → 公司打卡。迟到仍可继续完成，最终统一结算。

## 看预警，稳住重心

部分急躁的通勤者会沿自己的上班路线抢道。红橙色地面范围和箭头出现时，角色会先蓄力，再沿锁定方向冲撞，不会临时转向追你。你可以走出范围，或在命中前按住 Shift 稳住重心。

稳住会减慢移动，但能抵御主动冲撞的击飞；成功时有青绿色反馈环和文字提示，仍可能受到轻微推动。Space 冲刺没有无敌效果。可以在对方蓄力时主动冲刺打断，也可以绕开等待冲撞结束。

没有及时稳住时，主角也会被撞飞、翻转并落地恢复；腾空后再按 Shift 不会撤销这次受击。落地后有短暂保护，HUD 显示恢复与保护状态。保护结束前不会再次被强撞击飞，恢复结束后可正常移动。飞来的连锁身体不会额外造成无预警击飞。

## 暂停与设置

Esc 暂停/继续，暂停或结算页按 R 重开；M 切换声音。菜单和暂停页可开关轻微震屏。暂停会取消当前预警和主动冲撞，重新发起的冲撞仍须先预警；已经腾空的角色会冻结在当前状态，继续后完成落地。
