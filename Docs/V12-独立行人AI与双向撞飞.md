# V12：独立行人 AI、分区人流与双向撞飞

依据 2026-11-11 的补充要求：每个行人像正常早高峰通勤者一样独立行动；部分区域更密、任务区域留空；咖啡同事采用专用 AI；玩家冲刺撞人和路人撞飞玩家都加强，演出可以夸张。延续三阶段九任务、420 秒默认时限和占位美术。

## 每个人有自己的行程

V11 的共享局部环行线路已移除。每个普通行人保存自己的目的地、独立路径列表、速度与性格、决策计时器、等待耐心和随机序列；共享地图导航数据，不共享可变路径或行动状态。

- 普通通勤者独立选择可达的公共区域目标；赶路者走得快，慢行者会停留更久，谨慎者留出更多余地。高峰区的短途人流约 82% 选择节点两岸的不同目标，15% 前往相邻节点，3% 尝试长途行程；每次独立选择，不使用共享线路。
- 用真实地图网格和 A* 找路线，包含旁路和交汇处。局部避让预测约 0.8 秒内的相遇，选择继续走、从两侧绕过或等待，而非沿固定队列前进。
- 连续约 1.8 秒缺乏前进，会把前方拥堵作为额外代价重规划，保留原目的地；无法立刻通过时继续等待，不瞬移。
- 到达目标后按自己的性格短暂停留，再独立决定下一段行程。暂停游戏时，移动、等待、重规划和目的地切换一起冻结。
- 行人遵守双向红绿灯；绿灯已进入的人可以走完过街段。下车乘客各自持有出站目标，仍使用列车生命周期要求的清空车门行为，不参与普通通勤冲撞。
- 极端完全重合时按唯一身份确定分离方向，并通过正常地面碰撞逐步脱离；不靠传送恢复。
- 拥堵时可以按正常速度的 35% 或 65% 缓慢跟进；不再只有全速走和原地停两种选择。

当前目的地取自可通行的公共道路、广场、旁路及办公区。这是游戏内的通勤与短途停留 AI，尚不模拟完整城市的住宅、工作日程或经济活动。

## 密集段与任务空间

| 阶段 | V11 开局人数 | V12 开局人数 | 调整 |
| --- | ---: | ---: | --- |
| 街道 | 258 | 760 | 四个高峰节点集中汇流 |
| 地铁 | 298 | 900 | 三关中最密，换乘节点出现多排相向人流 |
| 办公室 | 244 | 700 | 公共走廊更拥挤，咖啡同事仍最多 40 名 |

约 80% 开局人口分配到模块 1、3、5、7 的四个高峰节点。范围沿主路中心向两侧延伸 18 单位，中部广场包含两侧肩部；高峰出生中心最小间距约 1.04，背景约 1.5。其余人口分布在连接路段，平行旁路权重较低。目的地分散在节点两岸及邻近节点，不把人堆在同一个中心点；持续的短途穿越与跨区通勤保持密度，人物仍自行移动、等待和绕行。

任务中心、推物操作区、文件交付点和下客区域保持保护；任务入口/回接处中央另留约 2.2×2.2 单位的行走空隙，普通行人从两侧通过。文件桌的行走保留半宽为 1.3 单位，冲撞保护仍为 2 单位，避免把绕桌通道挤成单列。普通通行与禁止冲撞的区域分别判断，NPC 不会替玩家推轮子、椅子、抹布或清理水渍。

密度报告在各模块用同样的 8 单位半径抽样，分别记录高峰段和较空路段均值、峰值，以及进入任务操作区的 NPC 数量；不能只用整张地图总人数判断拥挤感。

种子 91026 的开局采样：街道高峰/缓区均值 46.44/3.30，地铁 55.44/4.40，办公室 42.63/3.75；三阶段任务操作区人数均为 0。它们是同半径离散采样，不是整关平均值或帧率指标。

同一固定镜头覆盖约 26.67×15 单位，保持原正交尺寸 7.5。连续运行 60 秒后，四个高峰节点屏内人数分别为街道 128/87/70/113、地铁 132/97/112/167、办公室 61/83/108/93。各节点最近 10 秒净移动中位约 4.76–7.29 单位，真实穿过中心的不同演员约 14–31 名，说明人群仍在流动。没有 15 秒以上非预期停滞；地铁和办公室各出现一名约 10.5 秒的互等，不能表述为全员从不等待。详见 `V12-高峰密度持续观察.txt`。

持续观察曾发现办公区文件桌旁的单列互等。修正绕桌空间、让行时有限后退、以及使用玩家真实位移预测后，同一场景 280 人/60 秒观察中，超过 10 秒的非预期停滞由 11 人降至 0，最长停滞由 20.5 秒降至约 3 秒。这个结果限定该种子和站立玩家的观察条件。

性能方面，每次决策只收集一次近邻，静态任务保留区用空间索引筛选后仍做原来的精确边界判断。离玩家 28 单位以外的演员按各自 ID 错开，以累计真实时间每秒更新约 15 次；近处移动、碰撞、冲刺与腾空维持完整模拟频率。远处演员仍各自寻路和行动，不冻结或瞬移，暂停时也不推进。当前检查不替代目标设备帧率验收。

## 咖啡同事的专用行为

咖啡同事使用端杯状态机，行程围绕自己的公共办公区边缘停靠位置展开，避免把真正的文件交付工位当作普通 NPC 的目的地。

| 状态 | 行为 |
| --- | --- |
| 端杯行走 | 约 0.92–1.04 单位/秒，比普通人慢；局部避让留出额外个人空间 |
| 停步护杯 | 察觉玩家迎面冲刺时短暂停下并收紧姿势；不会获得碰撞免疫 |
| 到位短停 | 在自己的办公区边缘停留约 1.8–3.2 秒，再选择附近公共目标，然后返回 |
| 洒杯反应 | 真实接触触发，停步反应约 1.1 秒 |
| 空杯返回 | 沿实际路径回自己的位置，抵达后停留；被挤离超过 0.9 单位时重新寻路返位，本局不自动补杯 |

`spilled` 仍由原接触规则写入，同一人同一杯只记一次。护杯、再次接触、重新规划都不会重置账本，咖啡任务容忍值也没有放宽。咖啡同事不主动冲撞，不被玩家冲刺撞飞，但冲刺碰到仍会洒杯。

## 双向撞飞与夸张反馈

| 场景 | 实际移动/控制 | 视觉表现 |
| --- | --- | --- |
| 玩家 Space 撞普通人 | 一次冲刺可命中多名普通行人；同一次冲刺对同一人最多触发一次；NPC 自主飞行约 0.5 秒，地面位移上限 1.9 单位，0.8 秒保护 | 最高约 1.3 单位腾空、明显翻转和拉伸、落地约 0.18 秒回弹 |
| 赶路者撞到玩家 | 必须是自身前路被玩家挡住、耐心累积到约 0.8 秒；前摇锁定原路线，玩家让开会取消；玩家受击约 0.4 秒，保留 1.1 秒防连击 | 最高约 1.0 单位腾空、翻转、冲击圈、速度短线和落地回弹 |
| 玩家按住 Shift | 稳步/稳车，抵挡主动击飞；取消冲刺并阻止新冲刺 | 短促稳住反馈，身体压低 |

同时冲撞时，处于有效冲刺的玩家优先撞开普通路人，避免结果依赖谁先执行移动更新。下车乘客和咖啡同事不参与玩家撞飞规则；任务区、灯控区、站台和起终点继续保护。飞行者只由惯性运动逻辑更新地面位置，普通软推不会额外把它推过保护区。

腾空高度、翻转、冲击圈与回弹只影响表现；影子和排序仍落在地面，相机保持稳定，墙壁、任务物件和红灯仍然约束实际位移。NPC 落地后从实际落点重规划，继续原来的个人目的地。

飞行与落地期间固定翻转方向，碰墙停下或玩家改变输入不会反向跳转。落地从飞行末端约 300 度的姿态、缩放与中心轴连续承接，再平滑回到正常步态。

## 构建、证据与限制

Unity 6000.0.26f1，入口 `Assets/Scenes/EarlyRushV12.unity`。菜单 `Early Rush/V12/Validate and Build Windows` 或 `Tools/Build-V12.ps1` 输出 `Builds/EarlyRush-V12/EarlyRush.exe`。成品加 `--v12-runtime-qa` 会进行真实模拟输入检查并截图；每渲染帧推进四个模拟 Tick 的观察段不用于声明 FPS。

验证区分独立行为/碰撞专项、默认人口的持续运行、默认 420 秒的六条输入回放，以及实际成品截图。受控专项可以安排初始位置，之后必须通过输入和真实接触触发结果；不能手工补任务、设置击飞结果或清人群冒充整关完成。路线驾驶器会立即响应可见预警，其受击次数不代表人工操作难度。

加密后的首轮完整回放曾发现街道翻板驾驶器在远处预先缓存解，骑车转向的惯性擦到左板后仍执行旧解。误碰时最近 NPC 约 15 单位外，任务保留区人数为 0。修正限于验证程序：先通过实际输入到安全预备区，再根据实时板面逐步求解，并在抵达和触碰后重新确认；翻板规则、人口、时限和任务结果写入方式均未改变。最终街道结果采用修正后的专项复验，其他关卡采用同轮完整回放，原始记录与最终汇总分别保留。
