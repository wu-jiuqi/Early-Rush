# V14 首关美术接入说明

首章固定种子 91026 使用 EarlyRush_Art_v003 的真实 PNG 地块与拆件。其他种子和第二、三章仍保留原实现，本次不宣称三个章节美术全部重制。

## 坐标和地块
母图 887×1774，导出为 3 倍。World(px)=((px.x-375)/5,(1745-px.y)/5)。主路约 586.4 世界单位，9 段道路，3 个任务庭院。
实际导出边界 x=[0,1230,2661]，y=[0,1320,2430,3855,5322]；不是均等地块，更不是任意组合的自动地牢 TileSet。八块按真实边界回拼，不重叠旧地板。

## 渲染和交互
底图仍含烘焙的静态环境。早餐店、维修店和地铁入口是独立图层，按接地位置排序，遮挡角色时半透明。碰撞使用门面底部占地，不以整个屋顶大小阻挡人物。
轮胎、翻面板及信号灯使用真实 PNG，响应游戏实际状态。早餐提示框可见直径匹配 2.6 世界单位，维修提示框可见直径匹配 4.4 世界单位并居中任务目标；补偿了图片透明留边。提示框不改变原有圆形触发判定。
轮胎起点从母图 y=980 调整到 y=968，使玩家可站在后方推动；未采用瞬移或绕过任务条件。

## 测试与已知限制
坐标和几何测试通过 21 项。三章主线和全任务输入回放通过，证据见 QA/validation.txt。静态相机采样不等于真人通关测试。
首章环境和人物比例仍需优化，整图在近景放大后偏软，底图中的静态物体不能全部独立排序。尚未证明真实游玩时间达到每章 7–10 分钟。
