# V13 冲刺、小地图与沿路人流

本轮针对试玩中反馈的三点调整：冲刺频率和衔接不足、小地图人物位置偏移、人流过度集中导致连接道路空旷。占位美术继续使用，九项任务、420 秒默认时限和稳定北向镜头保留。

## 冲刺输入与收速

| 参数 | V12 | V13 |
| --- | ---: | ---: |
| 两次起冲之间的冷却 | 1.25 秒 | 0.65 秒 |
| 持续时间 | 0.24 秒 | 0.24 秒 |
| 步行/骑车峰速 | 8.2 / 9.8 | 10 / 11.2 |
| 尾段收速 | 回到普通加减速 | 最后 0.10 秒平滑降到前向普通速度；松方向则降到零 |
| 冷却尾端按键缓冲 | 无 | 0.14 秒，最多记一次按下 |

Space 仍按一次触发一次。冷却快结束时的按下可以接续下一次冲刺，过早按下不会一直蓄着，按住不自动连发。Shift 优先取消冲刺及缓冲；暂停、结算和被撞飞也清理待触发输入。暂停仍冻结冷却与受击保护计时，恢复不会自动消费暂停前的旧按键。

`TryDash` 保留立即尝试语义，实际键盘输入使用 `PressDash`。缓冲成功消耗时进入同一个碰撞管线，正常记录接触和撞飞；不会绕过红灯、墙体、咖啡账本或任务触发。

## 小地图坐标校准

旧版在基准 1280×720 下的底图和地面网格基本对应；主要问题来自在缩放后的 `GUI.matrix` 和局部坐标组中调用旋转。非基准窗口下，旋转支点与界面缩放/留白偏移没有处于同一个坐标系，会把箭头带离原位置。

V13 使用同一个北向投影对象计算底图世界裁切、纹理 UV、绝对虚拟 GUI 绘制区域及所有图标位置。取消小地图局部坐标组，箭头在原 GUI 矩阵右侧组合局部旋转矩阵，保持中心像素不动。屏外任务图标沿真实方位射线与边界相交，避免分别钳制 X/Y 后改变指向。

数值回归覆盖长横/长纵地图、纹理像素中心、源区域裁切、移动、不同窗口比例以及八个朝向。成品 QA 另在 1280×720、1024×768、1600×900 下，读取实际截图中的金色玩家标记连通块，以包围中心与质心偏向检查中心和朝向，并分别检查局部图和全图。独立按地图格子推算道路/空地地标，屏蔽任务图标及地形边缘，核对实际渲染；投影函数自反正确不能代替渲染验证。

成品结果：48/48 次箭头检查通过，包围中心估算最大偏差 1.99 屏幕像素，朝向点积 0.989–1.000；六个布局的道路 192/192、空地 192/192 地标匹配。六张保存帧均为东北朝向，其余朝向有逐次像素记录，未将单张截图当作八方向证据。

## 沿路覆盖与局部汇流

人数默认继续使用街道 760、地铁 900、办公室 700，咖啡同事最多 40。调整重点是让通勤者沿多个路段持续移动，公共连接路段有稳定的人流，在交汇处自然变密；任务操作区仍受保护，旁路更稀疏。

约 68% 初始人口按主路每 12 单位均匀分层放置，其余分布在九个交汇处；约 75% 普通行人进行跨路段通勤，其余访问相邻区域和公共侧路。主要行程在 58–155 单位内选择独立目的地，端部允许短行程到达外侧停靠带再掉头，避免提前折返留下空白末端。贯穿通勤者偏好经过主路拐角，方向不同使用转角的不同侧，仍逐段通过寻路与真实移动到达。

沿整条通勤主路每 12 单位、每 1 秒采样，而非只挑四个最密节点。记录 0/30/60 秒的各采样点可见人数、低人数采样、最长连续空路，以及明确排除的起终点 12 单位缓冲与任务操作区。独立目标、路径、让行、短停、真实碰撞和远处按个体错帧更新继续保留。

## 构建与证据范围

Unity 6000.0.26f1；场景 `Assets/Scenes/EarlyRushV13.unity`，构建入口 `Tools/Build-V13.ps1`，成品 `Builds/EarlyRush-V13/EarlyRush.exe`。`-Quick` 仅运行机制检查，不代表完整路线通过。成品加 `--v13-runtime-qa` 进行有明确初始摆位的渲染/机制检查并自动退出。

路线回放使用实际输入和当前板面求解，不写入任务结果；人流持续观察使用默认完整人口，不清人或传送 NPC。截图中的任务/连接路段取景和小地图校准会安排观察者位置，不能作为走到该处的证据。每渲染帧四个模拟 Tick 的 QA 也不作为 FPS 或人工难度结论。
