# 《早八冲刺》v6

把完整 ZIP 解压到一个新目录，打开 `EarlyRush-V6-Windows/EarlyRush.exe`。请保留 EXE、Data、DLL 和 MonoBleedingEdge 的相对位置。v5 可以单独保留。

主菜单按 Enter 或点击按钮开始完整三段通勤，按 C 进入地铁单段练习。

WASD / 方向键移动；空格冲刺撞飞；按住 Shift 稳住重心，移动较慢、不能同时冲刺。Escape 暂停，暂停/结果页按 R 重开；M 切换声音。

- 骑车：穿过两个街区，留意横穿路口的地面箭头。橙色预警区可以绕开或用 Shift 抗冲击。纸箱可用空格撞碎，或从左右绕过。
- 地铁：站厅会遇到逆向下车乘客，穿插前进；进入敞顶车厢后注意急刹预警，Shift 稳住或移到两侧安全位置。
- 公司：侧门会涌出同事，穿过大厅和办公区。到最后青色打卡垫后松开方向键，按住 Shift 约 0.8 秒完成打卡；未站稳可重新尝试。

预警出现后方向不会追着玩家旋转。橙色地面区是区域冲击，NPC 自己冲刺时的胶囊预警对应身体接触；两者都可用 Shift 防击飞。被撞飞后有落地恢复与保护；遇到挤堵可以松开冲刺、稳住并后退再换线。没有名额淘汰或永久失败，倒计时结束后仍可完成并得到迟到结果。
