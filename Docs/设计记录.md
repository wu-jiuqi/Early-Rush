# v6 三段通勤节奏

以 v5 的移动、双向强碰撞、预警、Shift 防守、落地保护和果冻表现为基础。扩展为每关 40×200 的连续地图，人物和相机比例沿用原版。不是新战斗系统，也没有新增耐力、淘汰名额或强制等待列车。

| 场景 | 连续空间与节奏 | 新的操作选择 |
|---|---|---|
| 骑车去地铁 | 第一街区施工绕行 → 纸箱捷径 → 第二街区横穿汇入 | 观察橙色横向箭头并侧移/稳住；冲刺撞开纸箱直接通过，或保留纸箱从侧面绕过 |
| 挤地铁 | 站厅前进 → 下车乘客逆向让行 → 车厢通道 → 地铁出口 | 在双向人流中穿插和冲撞；车厢急刹前稳住，或撤到两侧安全边缘 |
| 公司抢打卡 | 入口大厅 → 侧门涌出 → 办公通道 → 打卡区 | 躲开横向冲击再加速；最后松方向并稳住 0.8 秒完成打卡，被打断可重试 |

横穿/侧门事件先显示 1.2 秒固定方向地面范围，急刹先显示 1.3 秒；最多一个此类区域预警同时激活，重复触发有 7 秒冷却。区域击飞仍遵循原落地保护。危险判定用玩家中心与矩形范围，不沿玩家即时追踪，不以近场 NPC 是否实际接触作为触发条件。自然 NPC 强冲撞继续由原实体接触与独立胶囊预警决定。

站厅 12 名既有下车乘客不会开局就走光：接近 z78 时一次释放，最多 0.6 秒错峰；长时间不靠近则在 60 秒兜底放行。等待只延后自主导航，碰撞、被动位移和击飞照常，释放后不再挂起或传送。该批先逆向下车，再转到侧方接回目的地方向，最终沿原出口回收。

每关 152 个通勤者槽位，密度没有随地图面积翻倍；把人集中在路线与交汇处。物理根节点保持稳定，视觉子节点负责压缩、回弹、腾空和旋转。纸箱局部绕行搜索使用每次布局内的线段可达缓存，降低建场耗时，不能因此宣称所有运行长帧已解决。

共享准时目标为 230 秒，超时继续，不强制失败。熟练冲刺主路可以明显快于绕行；180–300 秒是开发时的节奏观测目标而非等待门槛。最终具体路线时长、受击/防守记录和性能以同一 Windows 构建的验证说明为准。

当前仍是 GameJam 原型：街区几何有复用，事件固定位置和方向，不是程序生成的长篇关卡。自动路线验证不替代真人对重复游玩、难度和手感的评价。
