# V11：冲刺、稳步与早高峰人流

依据：三阶段关卡设计 v3，以及 2026-11-11 新增的 Space 冲刺、Shift 稳步抗撞、恢复主动冲撞和增加人流要求。延续九项任务、每阶段 420 秒和占位美术；新增要求覆盖 V10 暂停冲刺的旧决定。

## 操作与冲撞规则

| 操作或状态 | 当前规则 | 反馈与边界 |
| --- | --- | --- |
| Space | 沿当前输入方向短冲刺；没有方向输入时沿朝向 | 持续 0.24 秒，按下后开始 1.25 秒冷却；步行速度 8.2，骑车 9.8 单位/秒；锁定本次方向 |
| 按住任一 Shift | 稳步，速度降至通常速度的 44% | 取消当前冲刺、优先于新的冲刺；骑车时减速稳车，不下车 |
| 普通擦碰 | 原有接触、软阻挡和任务碰撞记录继续生效 | Shift 抵抗主动击飞，不免除早餐碰撞次数，也不让咖啡免洒 |
| 路人主动冲撞 | 部分普通路人：蓄力 0.65 秒 → 沿预警方向冲撞最多 0.42 秒 → 收势 0.85 秒 | 有方向和蓄力提示，不追踪转弯；单人冷却 6 秒，全局间隔 1.35 秒，同时最多一人蓄力/冲撞 |
| 稳步抵挡 | 命中时按住 Shift，阻止击飞并使冲撞者收势 | 短暂稳住反馈；已被撞飞后按 Shift 不会瞬间取消腾空 |
| 未稳住被撞 | 0.34 秒衰减地面推力和最高 0.42 单位视觉腾空 | 1.1 秒连击保护；不扣生命、不额外扣计时；仍受地图和红灯约束 |

咖啡同事、下车乘客、横穿人群和边缘等候者不主动攻击。任务空间、灯控等待/过街区、下客区、起终点禁止普通路人进入或发动冲撞。玩家进入任务保护区，会取消正在进行的针对性冲撞。暂停冻结动作、冷却、人流和演出时钟。

## 人流分布

按真实道路切线/法线布置双向通勤带，不再沿全局 X 轴排三个原地晃动的人。每个可用直道路块形成连续的局部环行线路，转角/任务通道将路块分开，角色实际走过回转段，没有屏幕内传送刷新。

| 区域 | 分布与目的 |
| --- | --- |
| 奇数模块、有旁路的主路 | 街道/办公室约 2.6 单位纵向间距，地铁约 2.25；形成可见高峰段 |
| 其他主路 | 约 4.1 单位间距，给通勤提供恢复节奏 |
| 两条通勤带 | 道路法线两侧各约 1.1 单位，随道路转向；保留外侧通行空间 |
| 宽敞高峰段 | 少量间隔横穿者和路边等候者；仅当可走宽度足够时生成 |
| 旁路、转角、任务入口与操作区 | 低占用或留空，保留绕行、推物和停下操作的选择 |

出生和持续运动都检查保护区域；NPC 不会推动轮子、椅子、抹布，不会代替玩家清洁。邻近网格分桶处理人群避让，使用不同轮廓、色调和步态相位减少复制感。保护任务可读性优先于均匀铺满全图。

参数在 `ConfigV9` 的动作/人流 partial 定义中；人流种子固定可复现。该版用局部通勤环行建立拥挤感，尚不是城市级起终点寻路系统。

| 阶段 | V10 旧规则 | V11 | 变化 | V11 沿主路采样的最高可见数 |
| --- | ---: | ---: | ---: | ---: |
| 街道 | 147 | 258 | +75.5% | 24 |
| 地铁 | 147 | 298 | +102.7% | 27 |
| 办公室 | 150 | 244 | +62.7% | 23 |

旧人口用 V10 地图 JSON 复刻原采样/可走性规则计算；新可见数按 27×16 单位矩形、沿主路每 5 单位抽样，不是实时平均值或性能指标。种子 `91026–91028` 的九张图，开局共 227–298 人，最高局部可见数 23–27。10 秒模拟后大多数路人已移动超过 1 单位，同时检查未越界、未进入任务保护区、未推动任务物件或清理水渍。每人采用不同间距、速度及最大 0.28 单位的小幅横向漂移，路段端点收拢，避免笔直列队。

## 接入与验收

规则仍由纯数据模拟 `RunV9` 管理，表现层不写任务结果。动作状态由 `RushActionsV11.cs` 提供，人流由 `RushCrowdV11.cs` 提供；`RushActorPoseV11.cs` 只控制精灵姿态。腾空只偏移人物视觉，影子、碰撞和相机跟随保留地面坐标。后续序列帧可读取同一状态替换姿态表现。

使用 Unity 菜单 `Early Rush/V11/Validate Complete` 验证，`Validate and Build Windows` 对应 `BuildEarlyRushV11.Build` 先验证再构建。输出 `Builds/EarlyRush-V11/EarlyRush.exe`；`--v11-runtime-qa` 生成成品截图和运行报告。

验收分为受控动作专项、真实默认配置的人流运动检查、机器输入主线/三任务回放与成品截图。受控测试会布置局部场景，不能当作自然遭遇率证据；路线回放仅使用输入，不删人群、传送角色、补任务或延长 420 秒。最终结果另见同目录的 V11 验证结果与人流指标。

路线驾驶器会对可见前摇/冲撞立即按 Shift。六条路线回放未使用冲刺；冲刺和实际击飞由独立受控专项覆盖，因此路线中的零击飞不能推断自然操作难度。路线事件记录表明完整流程真实触发冲撞和稳步机制，不代表人工遭遇频率；最终次数见验证记录。
