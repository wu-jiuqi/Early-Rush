# Early Rush v0.8.0：碰撞通勤实现与验收

## 版本范围
基于 v7 (`b53607a`)，新增独立 `EarlyRush.V8` Runtime 与构建场景，旧版源码和场景保留。新分支 `dev/v8-collision-commute`，不会替换 v7 Release。Unity 固定 `6000.0.26f1`。

这版采用固定北向 XY 正交精灵场景与自定义圆形推动/网格扫掠碰撞。旧版 XZ 玩法没有混入新运行场景。W 永远上、D 永远右，角色转弯不会旋转输入坐标。

## 已编写的实现（运行验证状态见测试日志）
- 街道、地铁、办公室：各 3 项碰撞任务、420 秒独立倒计时、单独结算。
- 按时抵达得一星；完成至少一项任务得一星；全三项再一星。超时只有任务记录，不能解锁下一场景。
- 碰撞人流让人流让行并补充少量冲刺能量；无扣血、碰撞扣时、咖啡洒落或眩晕惩罚。
- 地图由确定性 seed 生成 9 段约 530–605 单位长的左右转折路线和三个双入口任务区；半径膨胀检查通行与推车空间。
- 街道：挤进咖啡店、推回卸货车、移开路障。地铁：沿途推背包、导流栏归位、行李车停靠。办公室：挤进打印区、文件车归位、三把会议椅归位。
- 物体到位必须先有真实推动、经过有序检查点并稳定停放；排队任务必须挤开两位不同人物。
- R 只让未完成物体回到合法检查点，不会直接完成任务。
- 雨、人流、清洁等限时事件有提前提示，避开目标区和最后45秒；具体数值待实际体验调优。
- 场景使用PNG，美术地板分别为沥青、瓷砖、地毯；物件按接地位置排序，高物件遮住玩家时淡化。
- 窗口失焦暂停，暂停不走计时，成功关卡最高星级保存本地。

## 操作
WASD 移动；空格冲刺；Shift 稳住；R 回位最近未完成任务物；Tab 地图；Esc 暂停；F1 说明。任务图标可点击查看简短说明。

## 构建
Unity 菜单 `Early Rush/V8/Validate and Build Windows`，或 batchmode executeMethod `BuildEarlyRushV8.Build`。
输出 `Builds/EarlyRush-V8-Windows/EarlyRush.exe`，分发必须连同 `_Data`、UnityPlayer.dll 等整个文件夹，不可只发 exe。

## 自动测试边界
`RushMapV8Tests.RunAll(100)` 检查300个stage/seed的路线、左右转、通行半径与扫掠；`RushV8Tests.RunAll()` 检查星级组合、计时边界、暂停、碰撞资格、检查点顺序及任务终态。
后者为了隔离规则，在检查点测试中直接安排物体位置，**不代表玩家实际沿全程推动通过**。
`--v8-qa` 运行自动测试并截图3场景，日志和截图写入QA目录；这是运行冒烟，不代表完整人工游玩验收。

## 必须实际验收
- Unity 无编译错误；Windows exe启动无异常、无缺图日志。
- 九任务至少各完成一次，背包全程推动不穿墙、不跳检查点。
- 每段可空任务通关及三任务满星；超时不进下一段。
- 两种方向转弯W/D不变；雨、人流出现前可预判。
- 各场景截图验证地板区别、俯视角、遮挡与碰撞脚印一致。
- 切后台不漏计时；长帧不穿墙；连续重试无重复回调。
- 用 Profiler 或运行数据报告性能，不从源码直接声称性能达标。

## 当前限制
程序化地图保留固定模板拓扑，只随机段长与镜像，不是无限任意地牢。精灵采用四方向图与轻量运动反馈，不是逐帧骨骼角色动画。事件和420秒时长需要真实游玩数据校准；不能把自动规则测试通过视为难度已平衡。
